Abstract

Overview

RASE (Reliability-Aware Suppression of Error Propagation) is a framework for reliable aerial-ground cooperative 3D object detection. It addresses Collaborative Perception Error Accumulation (CPEA), where unreliable information from heterogeneous agents can interfere with cooperative fusion and degrade detection performance.

The key idea behind RASE is simple: not all information shared between ground vehicles and UAVs is equally reliable. Rather than treating every collaborative feature equally, RASE estimates spatial unreliability and adaptively reduces the influence of potentially erroneous information while preserving useful complementary observations.

This project presents the RASE framework, experimental evaluations on V2U4Real and AirV2X, and RASE-sim, a simulated aerial-ground cooperative perception dataset developed for cross-domain generalization research.
